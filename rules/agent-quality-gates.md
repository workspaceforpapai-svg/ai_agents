# Agent Quality Gates

## Before work
- [ ] Read framework and project instructions.
- [ ] Inspect Git status and preserve user changes.
- [ ] Confirm task, acceptance criteria, and scope.
- [ ] Identify dependencies, risks, and approval gates.

## Before editing
- [ ] Trace relevant call sites and consumers.
- [ ] Understand current behavior and conventions.
- [ ] Identify tests and verification commands.
- [ ] Define file/module ownership.

## Before handoff
- [ ] Report files changed and decisions.
- [ ] Run relevant checks where possible.
- [ ] State exact test evidence.
- [ ] List unresolved questions and risks.

## Before completion
- [ ] Review the final diff.
- [ ] Confirm no unrelated changes.
- [ ] Confirm no secrets or sensitive data exposure.
- [ ] Confirm acceptance criteria.
- [ ] Report tests not run and limitations.
