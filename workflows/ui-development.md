# UI Development Workflow
1. Inspect current design system, routes, component patterns, and target breakpoints.
2. Define user flow, content hierarchy, component states, and accessibility needs.
3. Confirm API contract and loading/error/empty states.
4. Implement reusable components using existing conventions.
5. Test keyboard navigation, responsive behavior, validation, and error states.
6. Run lint, type checks, and relevant UI tests.
7. Compare against supplied design references when available; report deviations.
