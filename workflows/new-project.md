# New Project Workflow
1. Orchestrator collects goals, users, scope, constraints, and acceptance criteria.
2. Business Analyst documents workflows and business rules.
3. System Architect inspects constraints and proposes architecture with alternatives.
4. Database Architect proposes schema, ownership, tenancy, indexes, and migration strategy.
5. UI/UX Designer proposes journeys, design tokens, responsive layouts, and states.
6. Security Engineer reviews trust boundaries and sensitive flows.
7. Human approves scope, architecture, data model, and major dependencies.
8. Development specialists implement bounded milestones.
9. QA Engineer and Test Automation Engineer verify acceptance criteria.
10. Code Reviewer reviews the diff; Documentation Engineer updates docs.
11. Release Manager prepares readiness report. Human approves release/deployment.
