# Feature Development Workflow
1. Clarify requirement and acceptance criteria.
2. Inspect current behavior, usages, architecture, and tests.
3. Identify impacted frontend, backend, API, database, and integrations.
4. Write implementation plan and risk assessment.
5. Obtain approval for schema, auth, broad refactor, dependencies, or destructive changes.
6. Implement smallest complete vertical slice.
7. Add tests and update documentation.
8. Run focused tests, then relevant regression suite.
9. Request independent Code Reviewer and Security Engineer review when relevant.
10. Report files, behavior, test evidence, and remaining risks.
