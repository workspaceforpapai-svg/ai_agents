# Security Audit Workflow
1. Confirm authorization and scope of the audit.
2. Map assets, actors, trust boundaries, sensitive data, and entry points.
3. Review authentication, authorization, tenant isolation, input handling, uploads, secrets, dependencies, logging, and integrations.
4. Use safe static analysis and authorized tests only.
5. Record each finding with severity, affected component, evidence, impact, and remediation.
6. Do not exploit systems or alter production state.
7. Re-test fixes and report residual risk.
