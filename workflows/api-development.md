# API Development Workflow
1. Inspect current route/controller, DTO/validation, auth, response conventions, and consumers.
2. Define contract: method, path, request, response, errors, permissions, pagination, idempotency.
3. Confirm domain rules and tenant/resource ownership.
4. Review persistence and migration needs.
5. Implement validation, authorization, service logic, and safe error handling.
6. Add unit, integration, contract, and authorization tests as appropriate.
7. Update API documentation and examples.
8. Review rate limiting, logging, data exposure, and compatibility.
